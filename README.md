# Persian Text Preprocessing with Hazm and Parsivar

A Python project for preprocessing Persian text using the **Hazm** and **Parsivar** natural language processing libraries.

## Overview

The project applies common Persian NLP preprocessing techniques to a collection of Persian poems and prepares the text for further natural language processing tasks.

## Features

- Text normalization
- Sentence and word tokenization
- Stemming
- Lemmatization
- Stopword removal
- Punctuation removal
- Number removal
- English character removal
- Emoji removal
- Removal of single-character words and other noise

## Libraries

- Python
- Hazm
- Parsivar

## Preprocessing Pipeline

The preprocessing pipeline performs the following steps:

1. Load the Persian text files.
2. Normalize the text.
3. Tokenize the text into words.
4. Remove punctuation, numbers, English characters, and emojis.
5. Remove stopwords.
6. Apply stemming and lemmatization.
7. Save the processed text for further NLP analysis.

## Purpose

This project was developed as part of a Natural Language Processing course to explore Persian text preprocessing and the capabilities of the **Hazm** and **Parsivar** libraries.
